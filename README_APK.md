# APK automatic build

GitHub Actions automatically builds a debug APK on every push to `main`.

## Download
1. Open the repository's **Actions** tab.
2. Select **Build Android APK**.
3. Open the latest successful run.
4. Under **Artifacts**, download **adaptive-keyboard-debug**.
5. Unzip it and install `adaptive-keyboard-debug.apk` on the Android phone.

You can also open **Build Android APK** and choose **Run workflow** to build manually.

Android may ask you to allow installation of unknown apps for the browser/file manager used to open the APK.
